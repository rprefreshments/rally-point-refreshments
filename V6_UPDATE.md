## Install

1. Unzip this package.
2. Copy everything inside into the local GitHub Desktop repository.
3. Replace matching files.
4. In GitHub Desktop, commit:

   `Make 6-pack primary and remove pickup time`

5. Push origin.
6. Wait for the Cloudflare deployment to finish.
7. Open the live site in an Incognito window or hard refresh.
